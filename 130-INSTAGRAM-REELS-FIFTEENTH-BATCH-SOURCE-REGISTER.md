3. **Are.na** is a visual idea/reference collection platform, not a free asset license.
4. **OmniVoice** screenshot provides a logo/word only. **No uniquely verified canonical company/GitHub URL.**
5. **Five orange image-editing prompts** retain original text and typos: `behind it.Match` and `the the lighting`. All were preserved as a text library; none was executed.
6. **Cost screenshot** "$0" / "$20" figures are snapshot marketing and depend on current rate tiers, model/hosting configuration, storage and operations.
7. **Roo Code** original extension ceased operations in May 2026; a named historical skill should not be presented as a current default maintained service.
8. **LinkedIn agent skill** is for planning/drafts; it does not automatically publish.
9. **Antigravity/Better Auth/Neon credentials** in `.env` are secrets. Never paste actual keys in prompts or public documents and never assume “Antigravity handles the rest” without tests.
10. **Agency Agents / Agent Memory / OpenMontage** appear only as static text over bold black numerals **1, 4, 5**. Missing numbers 2/3 and canonical tool links were not invented. [129](129-AGENCY-AGENTS-AGENT-MEMORY-OPENMONTAGE-VISUAL-CARDS.md).
11. **RuView** is a hardware/firmware sensing research project requiring privacy/consent and real hardware calibration—not a universal software-only human detection claim.
12. **JEV** is a fast constrained browser agent, not a turnkey autonomous unlimited web access tool. Browser session/debug access and external API keys require care.
13. **Graft** is ambiguous across an enterprise workflow beta, dynamic MCP-generation offering, and codebase-memory tool; no canonical single match selected.
