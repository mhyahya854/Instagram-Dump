## Crucial factual corrections

- Stanford's 49% refers to **11-model average** in specified studied advice prompts, not a Claude-specific measurement; source https://doi.org/10.1126/science.aec8352 .
- JWTS: deleting an account/refresh token doesn't invalidate already-issued access tokens before their expiry if validators only check token crypto. Critical actions should check live account status / revocation.
- No external skill guarantees no malware or exploits. Dependency tooling, PR reviewers and AI adversarial opinions are complementary, not security certification.
- “Reticle verifies after every change” requires the SDK/instrumentation, saved flows and proper configuration; actual coverage and platform conditions matter.
- Lemo Opuscar's original “43 styles” catalog has been expanded, so count needs version/date.
- HyperFrames, One Take, Collage B-roll, Claude Animation Base and Lemo Opuscar are **different kinds of source** (renderer, camera grammar, visual technique, character kit, style library), not interchangeable plugins.
- Creator-supplied ElevenLabs script prompts, “kit,” and exact “Claude Design” steps were **not supplied**, so no copy of the private kit is asserted.
- “Suno” music, cloned voices and source screenshots may require creator and commercial usage rights.
- “No plugins” and external skill upload plus commercial speech/music services are different concepts; preserve without promising zero-setup/offline operation.
