## Project workflow rule candidate: prevent partial compliance

1. Define outcome, scope, user needs, permissions and unchangeable constraints.
2. Convert requirements to individually numbered acceptance checks BEFORE implementing.
3. Give each independent task a reviewer and concrete proof artifact.
4. Run the minimum relevant skill; no global pile of all plugins.
5. Test the scoped result, record actual command results and screenshots.
6. Re-run integration/negative checks when changes merge.
7. Complete only if all required evidence passes; otherwise clearly report PARTIAL, BLOCKED or UNTESTED.
8. Preserve audit logs and human consent for destructive, financial or public actions.

An AI's own description of success is **not objective evidence**. Unlazy's verification gates are useful but executable shell gates require scrutiny and permission control.
