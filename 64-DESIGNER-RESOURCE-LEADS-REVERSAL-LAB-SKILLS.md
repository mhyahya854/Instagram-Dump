## Why designer resources shouldn't become software defaults

- A catalog is for **learning and choosing**; it is not permission to inject dozens of animations or styling packages into every site.
- Study principles like reading flow, hierarchy, timing, tactile feedback and spatial continuity.
- Licensed fonts and reference assets remain rights-managed, even if screenshots appear in free galleries.
- Paid community/bootcamp names, free GitHub starter skills and public documentation belong to separate cost/source categories.
- Skill repositories can contain executable scripts or permission requests; no unreviewed source should be run or installed solely because it appears on Instagram.
