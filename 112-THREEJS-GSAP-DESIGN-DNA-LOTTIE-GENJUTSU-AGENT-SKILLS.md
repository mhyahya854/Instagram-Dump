## Canonical verified source repositories

### 1. Three.js skills — source owner correction

**https://github.com/CloudAI-X/threejs-skills**

The source screenshot spells `ClaudeAI-X`, but GitHub repository search and a README fetch identify **`CloudAI-X/threejs-skills`**. This is a **critical literal correction**, not a silent change to the original caption. The skill targets specific Three.js and React Three Fiber / drei versions (README lists three r186, R3F 9.8, drei 10.7, gltf-transform 4.5 at capture). It supplies current APIs, examples, common mistakes and WebGL/WebGPU notes; the skill itself is **not the Three.js runtime**.

**Use:** correct scene graphs, cameras, PBR lighting, GLTF optimization, particles and resource cleanup. Test actual GPU, loaders, accessibility (keyboard alternatives), controls, mobile battery/FPS, context loss and reduced motion.

### 2. GSAP official skill

**https://github.com/greensock/gsap-skills** · runtime https://gsap.com/

This repository self-identifies as **official GreenSock AI skills**, explaining timeline/tween patterns, ScrollTrigger, plugins and framework integration. GSAP's runtime and agent skill are separate. Use for choreographed timeline motion, responsive state transitions, scroll-linked meaning, intro/outro text. Test viewport behavior, reduced motion, hydration and cleanup. Don't impose mandatory scroll hijacking or animations with no user value.

### 3. Design DNA

**https://github.com/zanwei/design-dna**

Machine-readable visual identity extraction using **design tokens, qualitative style, visual effects**. Applied appropriately, it documents layout logic, typography, spacing, colors, treatments, motion references and transferable principles. **“Copy any UI style” is a promotional source bullet, not permission to clone proprietary pages, logos, images, fonts or protected site source.** Use with original project direction and rights-cleared assets; confirm concrete font license and responsive usage.

### 4. Motion Design skill

**https://github.com/LottieFiles/motion-design-skill**

LottieFiles describes a **philosophy-first implementation-independent motion-direction skill**, not simply a library of pre-rendered Lottie files. Covers timing, easing, choreography, state changes, emotional intent and motion systems such as CSS, GSAP, Motion, SVG and Lottie. Use motion only when communicating hierarchy, cause/effect, continuity or feedback. Include reduced-motion and time/perf budgets.

### 5. Genjutsu

**https://github.com/AThevon/genjutsu** · https://genjutsu.athevon.dev/

A set of Claude Code skills oriented around giving websites distinct motion, product style and layout. The source screenshot's **“award-winning UI”** is promotional and does **not prove every generated site won an award**. Use for concept ideation, responsive sections and creative polish after product content and interaction fundamentals. Review scripts, network side effects, token/license and compatibility before adoption.

## Rulebook mapping

**Three.js** = graphics/3D implementation. **GSAP** = explicit animation sequencing. **Design DNA** = consistent identity/tokens. **Lottie Motion Design** = intent, timing and motion-system judgment. **Genjutsu** = overall composition, creative direction and polish. They are **complements, not an automatic “install all five” stack**.

### Before installing any external skill

1. Inspect repo and target commit, `SKILL.md`, prompts, code, install scripts, permissions, remote endpoints and licenses.
2. Never run `npx skills add` or cloned scripts merely because an Instagram creator recommends them.
3. Decide one project-specific purpose, compare available native tools, pin compatible versions, test in a sandbox.
4. Keep source media and provenance. Don't silently reproduce site screenshots pixel-perfect from other brands.
5. Add tests for keyboard/mobile, actual state transitions, visual review, hover/focus, reduced-motion, asset sizes and FPS.
