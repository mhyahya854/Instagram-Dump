## How the Google catalog is structured

Folders cover Google Cloud AI inference/evaluation, GKE, infrastructure/operations, databases, developer API tools, security/identity, Ads, Analytics and developer skill discovery. Files under `skills/{category}/{slug}/SKILL.md` contain concrete instructions. The index below uses upstream `name`, `entrypoint`, and shortened `description`; **descriptions are upstream claims**, not endorsements or independently measured functionality.

Google documents optional installation through `npx skills add google/skills` with selection of skills and target agents; plugin bundles and compatibility manifests also exist. **No skill was installed or executed.** Avoid installing all merely because they are indexed: many may create cloud resources, spend money, change IAM, delete data or access credentials.

## Operational permissions, privacy, compatibility and cost

- **Installation:** package/CLI installers can execute scripts and change config. Inspect manifests, exact git commit, code owners and dependencies first. Project-level install is preferable to global installation.
- **Security:** read-only review before provisioning/deleting cloud resources. Apply least-privilege IAM, explicit spending limits, audit trails, secrets manager, environment isolation and approved backups.
- **Privacy:** Workspace skills may read mail, documents and calendar events; Google Cloud may expose sensitive business datasets. Do not grant access merely to test skills.
- **Model independence:** markdown-based skills may port to Claude Code, Codex, Gemini CLI and other harnesses, but runtime-specific scripts/tools can require a particular provider, OS, CLI or service. Verify each.
- **Licensing:** the main `google/skills` repo declares Apache-2.0; this does not relicense referenced cloud services or third-party assets. Other repos have their own licenses.
- **Validation:** choose one real task, pin source, run sandboxed synthetic data, measure success/latency/provider costs and quality regression. Unverified vendor efficiency claims are not benchmark findings.
