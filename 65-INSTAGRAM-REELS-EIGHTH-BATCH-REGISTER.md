## Correctness and adoption boundaries

- A video saying “every time produces a unique design” is a promotional claim; visual skill and registry usage cannot guarantee originality, accessibility, licensing or functional behavior.
- 21st and shadcn MCP can introduce code/dependencies or require external access; skill names are not approval to install.
- Supabase Agent Skills provide instructions; a connected Supabase MCP may operate live data with additional authenticated permissions.
- A font identified in a gallery is **not** permission to download/redistribute the font from the original site.
- SiteInspire is **not confirmed as the third original video source**, only an independent, functional match for minimal editorial design.
- Reversal Lab is **not Reverse Engineer Anything** without evidence.
- Skip one-to-one copying of protected animations/art, unsupported commercial claims, gratuitous UI effects, and untested app behavior.
