## Meaningful distinctions

This infographic markets all ten as “Claude repos”, but they are **not** interchangeable: REA is security/engineering investigation; Ponytail, Hallmark, Humanizer, Impeccable, UI/UX Pro Max, Last 30 Days and Diagram Design include agent instructions/skills; **Onyx** is an application platform; **Scrapling** is a developer library with agent interfaces. Most do **not** need to be installed together.

**Hallmark is verified:** https://github.com/Nutlope/hallmark . Earlier archive research about an “anti-slop” skill now has an exact source. It describes building around user tasks, picking a visual structure and auditing common generic AI design markers.

**Diagram Design is verified:** https://diagramdesign.dev/ and https://github.com/cathrynlavery/diagram-design . It emits useful offline HTML+SVG and has multiple diagram types; this is relevant to the eventual knowledge-archive diagrams.

## Reference-only evaluation protocol

1. Choose tool based on one existing need. Never install ten arbitrary scripts as a “must-have” stack.
2. Verify current publisher/source and license, read SKILL.md/installers, inspect subprocess and external account/secret permissions.
3. Test in an isolated fixture; compare actual output against a prior baseline and a project-specific definition of done.
4. Pin a version/commit and retain rollback, cost and privacy notes.
5. Never interpret GitHub stars, a screenshot rank or “senior developer” title as proof of safety or quality.
