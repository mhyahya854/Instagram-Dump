## Watermelon UI

- https://ui.watermelon.sh/ · source repo https://github.com/WatermelonCorp/watermelon-platform
- Website describes open-source React components, interactive animations, blocks, dashboard layouts and templates; supports developer endpoints and machine-readable references.
- **Use:** borrow interaction/state patterns and functional React component examples for owned projects, then adapt to actual typography/spacing tokens, keyboard semantics and performance. Website marketing “600+ components” is a changing catalog claim; check exact component availability and license in the repo version.
- Avoid copying default aesthetics across all apps simply because assets are available.

## Motion Primitives

- https://motion-primitives.com/ · official https://github.com/ibelick/motion-primitives
- Motion and Tailwind-based animated React interface primitives (text effects, transitions, menus, micro-interactions). Official docs https://motion-primitives.com/docs/installation .
- **Use:** focused narrative transitions, responsive feedback and visual motion using actual app state; verify reduced-motion handling, focus/keyboard paths, interruption, hydration, bundle cost and mobile FPS.
- Components are optional; animations with no purpose become visual clutter.

## Manus

- https://manus.im/ · general-purpose cloud agent product offering research and computer-based task execution, rather than a React UI design component library.
- Official product announcements establish a business/service with changing ownership and data/access policies; investigate current terms/region availability before using.
- **Use:** agentic task orchestration comparisons, not interchangeable with motion primitives. Any tool access to third-party accounts and external actions needs explicit consent and security review. Do not assume free, local or open source from a video heading.

## Haikei

- https://haikei.app/ · official generators https://haikei.app/generators/
- Browser generator for abstract design backgrounds: waves, blobs, layered steps, low-poly grids, gradients, SVG/PNG export. Official site advertises 15 free generators, no account required at capture.
- **Use:** supporting visuals for section breaks, poster/cover, hero backgrounds or delicate section separations. Keep backgrounds decorative, don't obscure text or imitate an entire reference brand. Verify accessibility/contrast, export format rights and asset size.

## Selection guidance

Watermelon UI = interactive components/blocks; Motion Primitives = designed movement; Haikei = scalable decorative art; Manus = autonomous task agent. Their inclusion in the **same Instagram reel** does **not** make them substitutes or a required toolkit.
