## Cross-cutting decisions

1. **Do not treat a GitHub star-count snapshot as permanent**; verified highest-rank claim refers to October 2026, not an immutable all-time invariant.
2. **Use education projects to acquire understanding**, not promise homemade Git/database/container libraries are security-hardened infrastructure.
3. **UI, UX and CX overlap**, so avoid the false rigid rule “UI only looks, UX only works.”
4. **Sunehra / golden edit kit** has no verified canonical GitHub link or recovered private 40+ skill payload.
5. **OpenGym media files have different licensing from its AGPL source code**: archiving software or reusing assets requires rights review.
6. **Five agent personas are not five independent professional evaluators**; practice feedback is advisory, with privacy/fairness requirements.
7. **Reverse-engineering skill** may support authorized interoperability and learning, not license/DRM bypass or copying proprietary code.
8. New entries are **research/catalog only**. No app, skill, model or helper script was installed or executed.
