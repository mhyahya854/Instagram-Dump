## Similar name, **different product**

- [Humanizr/Humanizer](https://github.com/Humanizr/Humanizer) is a **.NET string/case/number/time formatting library**. It does **not** serve the purpose of editing AI-generated prose. Retain as a naming collision to prevent wrong installations.
- Python/text-normalization, web humanization services, and security “humanizer” obfuscation tools are distinct categories; do not download executables or proxy user data to unknown websites based on name alone.

## Usage contract for any writing humanizer

1. **Truth/meaning immutable:** preserve dates, figures, claims, scientific terms, references, attribution, hedging, and explicit uncertainty.
2. **Voice and audience:** take the user's real writing samples, style guide and required register (academic, friendly, technical, legal).
3. **Remove repetitive formulae**, excessive generic intensifiers, fake expertise, filler, unsupported certainty, monotone structures and fabricated “personal experience”.
4. **Human-authored review** after transformation: ensure terms, claims, citations and originality remain accurate.
5. **No misleading authorship** or fabricated first-person observations. Humanizer is for readability/authentic voice, **not evading academic integrity rules, provenance disclosures or AI detection tools**.
6. Compare output with a paragraph-specific before/after, semantic factual delta, token count and feedback. Choose one compatible skill where possible; don't globally load every variant.
7. Audit bundled commands, update/install scripts, repo supply chain, license and target-platform permissions before running.
